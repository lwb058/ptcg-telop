# dashboard/css/
> L2 | 親: [../CLAUDE.md](../CLAUDE.md)

操作画面の共通スタイル。各 HTML と動的な描画処理が同じセレクターを使い、状態クラスを変更して選択・ドラッグ・非アクティブ表示を切り替える。

## メンバー
- [dashboard.css](dashboard.css): 7 パネルから直接読み込む共有 CSS。フォーム・ボタンを基礎に、盤面、操作履歴、デッキ／サイドカード、設定画面のレイアウトと状態表示を定義する。スタジアム背景は非回転の battle-field-wrapper が描画し、透明な内側の盤面だけを観戦視点で回転する。
