# graphics/css/
> L2 | 親: [../CLAUDE.md](../CLAUDE.md)

配信画面と SlotRenderer が生成する DOM に対し、共通の配置・演出・書体を定義する。画面固有の CSS とテーマはこの既定値を上書きする。

## メンバー

- common.css: 1920×1080 の透明画面とバトル場・ベンチ・縮小ベンチ・選手情報の共通スタイル。素材と配色の CSS 変数、入退場・攻撃・HP 変化の演出を提供し、3 画面が読み込む。
- fonts.css: 配信素材のローカルフォントを @font-face で登録し、body の言語クラスから本文・ワザ名・選手名の書体変数を選ぶ。各画面のフォントプリロード処理もこの URL 定義を参照する。
